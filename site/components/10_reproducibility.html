Data Availability & Reproducibility

Open Science Statement

This work follows strict open-science practices. All results are fully reproducible from raw data using the documented pipeline. All numerical results, figures, and statistics are generated by deterministic Python scripts processing real observational data.

Repository & Code

GitHub Repository: github.com/matthewsmawfield/TEP-COS

The repository contains a deterministic, version-controlled analysis pipeline with 19 analysis steps across two primary channels (Pulsar Timing and Gravitational Lensing).

Reproduction Instructions

Quick Start (Full Reproduction)

# 1. Clone repository
git clone https://github.com/matthewsmawfield/TEP-COS.git
cd TEP-COS

# 2. Install dependencies
pip install -r requirements.txt

# 3. Run master reproduction script
python reproduce_manuscript.py

# 4. Build manuscript site
cd site
npm install
npm run build

Pipeline Overview

The analysis is organized into 19 deterministic steps across four sections:

  1. Helper Step: Data format conversion (CDS to RDB)
  2. Section 3 (Pulsar Timing): 9 steps covering maximal sample construction, population controls, density scaling tests, binary analysis, and radial diagnostics
  3. Section 4 (Lensing): 7 steps including temporal shear analysis, validation, instrumental consistency, and high-z cluster lenses
  4. Section 5 (Synthesis): 1 step — TEP summary figure
  5. Appendix: 1 step — SN Ia stretch test

Key Analysis Outputs

  • results/outputs/step_5_10_pulsar_population_controls.csv — Main pulsar dataset (380 MSPs)
  • results/outputs/atnf_psrcat.db — ATNF catalog (auto-downloaded)
  • results/outputs/step_3_0_cosmograil_temporal_shear_opB_modejump.json — Canonical lensing results
